Temenos T24 Core Banking System

Temenos T24 exposes two deterministic ingress APIs on port :9100:

POST /api/v1/t24/funds-transfer
OFS: FUNDS.TRANSFER,AUTH/I/PROCESS
• Real-time balance mutation
• Double-entry general ledger
POST /api/v1/t24/reversal
OFS: FUNDS.TRANSFER,REVERSE/I/PROCESS
• Triggered by Saga Coordinator
• Reverses debit/credit upon downstream failure
Database Segregation Rationale
BFF DB vs CBS Master DB

BFF Database (PostgreSQL :5433): Owns UI session state, mobile form drafts, user preferences, and aggregation caches.

CBS Master DB (Azure SQL :1433): Strictly owned by Temenos T24. Stores account balances and GL journals.

Benefit: High-throughput client polling and draft editing never cause lock contention or degrade core banking ledger throughput.
