Key Highlight: Dual-Endpoint T24 CBS
Temenos T24 Core Banking System

Temenos T24 exposes two deterministic ingress APIs on port :9100:

POST /api/v1/t24/funds-transfer
OFS: FUNDS.TRANSFER,AUTH/I/PROCESS
• Real-time balance mutation
• Double-entry general ledger
POST /api/v1/t24/reversal
OFS: FUNDS.TRANSFER,REVERSE/I/PROCESS
• Triggered by Saga Coordinator
• Reverses debit/credit upon downstream failure
Persistence Model: CBS DB vs Audit Vault
Azure SQL vs PostgreSQL 16

CBS Master DB (Azure SQL :1433): Strictly owned by Temenos T24. Stores account balances and GL journals with row locks.

Audit Vault (PostgreSQL 16 :5432): Append-only compliance repository with DB triggers rejecting UPDATE and DELETE.

Zero External DB Sprawl: All application business workflows operate directly through standard microservices and core banking databases.
